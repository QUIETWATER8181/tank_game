# 新模式界面检验

启动原有游戏，点击主页“开始游戏”。三个工作区（车间 / 坦克仓库 / 第一关）都已接入数据服务，页面刷新后可从本机仓库读取草稿、模型和成品。3D 场景是写实代理；**第一关已经能开、能打、能分出胜负**。

> 界面语言：整页是一张手绘军工档案纸。左栏是「部件清单 / 可装部件 / 当前部件 / 备注」，中间是贴着胶带的照片（里面是实时 3D 视口）+ 下方的手绘平面布置图，右栏是「验收单」。字体为行楷（标题）、楷体（正文）、Ink Free（数字），表格线是 SVG 波浪线，重绘不会错位。

## 建议检验顺序

1. **车间**：默认提供步坦蓝图（车体、履带、引擎、炮塔、火炮）。首次进入会弹一次三步引导（`?noguide=1` 可跳过）。左栏底部“附页：蓝图 / 外观 / 草稿 / 模型仓库”折叠区里可以新建其他类型的蓝图，之前的修改会先保存为草稿。
2. **安装部件**：点击“可装部件”里的行。车体、履带、引擎、炮塔各只能装一个（装上后从列表消失），武器最多 4 件，装甲可叠放。新部件会自动寻找不重叠且能连接的位置；付费部件先扣“零件”解锁，同一部件不会重复扣费。
3. **3D 摆位**：点击照片里的部件选中（琥珀色框 + 地面圆环），按住拖动时**部件与鼠标 1:1 跟手**；拖动中会出现半透明 ghost 预览，绿色合法 / 琥珀色会重叠 / 红色穿地或超界，同时用圆环高亮将要连接的父件。松开鼠标才吸附到 0.1 m 网格并贴到最近的连接件。拖动中滚轮旋转 15°（Shift 5°）。按住 Shift 拖动调高度，拖动空白处旋转视角，右键平移，滚轮缩放。
4. **操作行**（左栏「操作」下）：撤销 / 重做、逆时针 / 顺时针 15°、升高 / 降低、吸附网格（0.1 m → 0.25 m → 自由）、复制、删除。快捷键：Q / E 旋转、Delete 删除、Ctrl+D 复制、Ctrl+Z 撤销、Ctrl+Y 重做、方向键平移（Shift 加速）。一次拖动只产生一次撤销。
5. **结构检查**：把武器或装甲移远会显示“未接触所连接的部件”等错误，验收单变成「需要调整」，制造按钮禁用；移回或撤销即可恢复。验收单默认显示结构校验、连接完整性、整车质量、最大外形、武器挂载、稳定性（红笔圈出）、类型适配、生命/移速；“全部数值与计算依据”折叠区里有攻击、攻速、转向、弹道与公式。
6. **保存**：编辑后约 0.9 秒自动保存草稿（底部状态显示“有未保存修改 / 草稿已保存”）。也可以点击“保存草稿”。“制造并入库”会把当前蓝图快照写入坦克仓库，之后改草稿不影响成品。
7. **领取测试零件**：每份存档一次，共 100 零件，仅用于新模式检验，与旧小游戏钱包独立。
8. **模型仓库**：车间“附页” → “打开模型仓库”。选择场地 / 敌坦 / 玩家坦克分类，导入内嵌贴图 GLB，确认预览后点击“保存到模型仓库”。保存前文件只是临时预览。
9. **绑定外观**：玩家模型入库后，在车间“高级 → 成品外观模型”中选择它，再制造一辆坦克。该模型只影响外观，不改变蓝图能力。
10. **坦克仓库**：点击“检验”显示评估与外观；点击“准备第一关”进入关卡。
11. **第一关（非战斗）**：进入后镜头从玩家坦克后方看向 36 × 180 米的三段式场地（接敌区 → 侧翼区 → 基地攻坚）。右下角镜头胶囊可切换“看玩家 / 全景 / 基地 / 敌坦”，关卡内还可用 W / A / S / D 平移镜头。
12. **开战**：点击“开战”（第一关页签唯一主按钮）。场景重建一次并进入战斗：
    - **W / A / S / D** 驾驶（限速 + 阻尼 + 差速转向；泥地与碎石会降低可达速度，但右侧数值不变）。
    - **鼠标**瞄准：准星指向敌坦时直接取命中点，指向地面时按“这里站着一辆坦克”解算仰角；指向天空则按最远射程。
    - **左键 / 空格**开火，装填 1 秒（主武器 `fireRate`）。
    - 镜头跟随车体（不跟鼠标），屏幕中央有准星，顶部 HUD 显示生命 / 装填 / 剩余敌坦 / 基地血量。
    - 敌坦按触发线接敌：转车体、保持约 22 m 推进、对准后开火。被击毁的敌坦变成冒烟残骸。
13. **胜负**：4 辆敌坦 + 基地全部摧毁 → “胜利条件达成”；玩家阵亡 → “失败条件达成”。结束后战斗自动停止、镜头解锁、场景重建一次展示残骸。
14. **规则自检（开发者）**：第一关面板底部 `<details>规则自检（开发者）` 里保留“模拟消灭 / 模拟摧毁基地 / 模拟玩家阵亡”，直接向状态机发事件，不经过战斗模拟。可“重新准备”或返回仓库，下一关保持禁用。

## 当前边界

- 坦克是程序化写实代理：车体、炮塔、火炮、履带、路轮、装甲和附件都由部件尺寸生成，仍不是最终美术资产；外观 GLB 只在成品预览时替换。
- 部件碰撞使用旋转后的包围盒，斜面或倾斜装甲可能被保守判为重叠；没有插槽、凸体、承重、供能或炮口遮挡检查。
- 战斗是**运动学 + 弹道**，不是刚体物理：没有悬挂、坡度、翻车，也没有散布 / 瞄准时间（字段已留）。迫击炮的 `impactDelay` 尚未模拟。
- 敌坦没有寻路、不会躲掩体、不会协同，会互相卡在掩体上；掩体除弹药堆外不可摧毁。
- 基地血量对应整个院落的包围盒；院内两个弹药堆在包围盒之前判定，所以可以单独打爆并连锁。
- 场景标签、烟尘和旗帜是表现层动画，不参与规则。
- 仓库依赖浏览器本地存储，不跨浏览器、端口或设备同步。存储不可用会显示错误，不会无提示切换成临时存档。
