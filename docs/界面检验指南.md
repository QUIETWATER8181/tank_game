# 新模式界面检验

启动原有游戏，点击主页“开始游戏”。四个工作区都已接入数据服务，页面刷新后可从本机仓库读取草稿、模型和成品。3D 场景是写实代理与关卡布景，尚未运行真实战斗。

## 建议检验顺序

1. **车间**：默认提供步坦蓝图（车体、履带、引擎、炮塔、火炮）。选择类型后点击“新建蓝图”体验其他类型，之前的修改会先保存为草稿。
2. **安装部件**：点击部件目录里的卡片。车体、履带、引擎、炮塔各只能装一个，武器最多 4 件，装甲可叠放。新部件会自动寻找不重叠且能连接的位置；付费部件先扣“零件”解锁，同一部件不会重复扣费。
3. **3D 摆位**：点击 3D 中的部件选中（浅黄色框 + 地面圆环），按住拖动即可移动；松开后自动吸附 0.1 m 网格并重新连接到最近部件。按住 Shift 拖动可调高度，拖动空白处旋转视角，右键平移，滚轮缩放。
4. **工具条**（视口下方）：撤销 / 重做、逆时针 / 顺时针 15°、升高 / 降低、吸附网格（0.1 m → 0.25 m → 自由）、复制、删除。快捷键：Q / E 旋转、Delete 删除、Ctrl+D 复制、Ctrl+Z 撤销、Ctrl+Y 重做、方向键平移（Shift 加速）。朝向滑杆拖动时 3D 实时跟随，松开后写入草稿。
5. **结构检查**：把武器或装甲移远会显示“未接触所连接的部件”等错误并禁止制造；移回或撤销即可恢复。右侧报告同时给出质量、尺寸、稳定性、类型适配、炮塔转向和公式说明。
6. **保存**：编辑后约 0.9 秒自动保存草稿（底部状态显示“有未保存修改 / 草稿已保存”）。也可以点击“保存草稿”。制造并入库会把当前蓝图快照写入坦克仓库，之后改草稿不影响成品。
7. **领取测试零件**：每份存档一次，共 100 零件，仅用于新模式检验，与旧小游戏钱包独立。
8. **模型仓库**：选择场地 / 敌坦 / 玩家坦克分类，导入内嵌贴图 GLB。确认预览后点击“保存到模型仓库”。保存前文件只是临时预览；仓库中的文件可重复预览。
9. **绑定外观**：玩家模型入库后，在车间“成品外观模型”中选择它，再制造一辆坦克。该模型只影响外观，不改变蓝图能力；绑定随本次制造生效，不写入草稿。场地和敌坦尚未提供关卡绑定。
10. **坦克仓库**：点击“检验”显示评估与外观；点击“准备第一关”进入关卡场景。
11. **第一关**：进入后镜头从玩家坦克后方看向走廊。顶部可切换“自由视角 / 自动环绕 / 复位”，车间面板里有“看玩家 / 看全景 / 看基地 / 看敌坦”和每辆敌坦的“视角”按钮；关卡内还可用 W / A / S / D 平移镜头。
12. **胜负测试**：点击“开始规则测试”，手动模拟消灭敌人、摧毁基地或玩家阵亡。只摧毁基地不会胜利；4 辆敌坦和基地全部销毁才胜利。玩家阵亡会失败。被消灭的敌坦会变成冒烟残骸，基地被摧毁后旗杆与雷达停止、出现浓烟。可重新准备或返回仓库，下一关保持禁用。

## 当前边界

- 坦克是程序化写实代理：车体、炮塔、火炮、履带、路轮、装甲和附件都由部件尺寸生成，仍不是最终美术资产；外观 GLB 只在成品预览时替换。
- 部件碰撞使用旋转后的包围盒，斜面或倾斜装甲可能被保守判为重叠；没有插槽、凸体、承重、供能或炮口遮挡检查。
- 第一关是静态场景检验：敌我坦克、道路、路障、瞭望塔、基地和残骸都只是布景，没有 AI、弹道、物理、移动或伤害结算。所有销毁操作明确是测试事件，不发放奖励。
- 场景标签、烟尘和旗帜是表现层动画，不参与规则。
- 仓库依赖浏览器本地存储，不跨浏览器、端口或设备同步。存储不可用会显示错误，不会无提示切换成临时存档。
